  • <POD> port of discharge (with code)
  • <CARRIER> carrier(s)
  • <TRANSIT> transit days
  • <VALIDITY> rate validity window

  • <CONTAINER> container type

  • <SURCHARGES> checked surcharge lines
  • <EACH_LANE>…</EACH_LANE> repeats per lane (POL→POD)

          Carrier credentials — password vault

          Store login credentials per carrier so you don't have to remember them across devices. Passwords are AES-256-GCM encrypted at rest with a key in .secrets/secrets.key (gitignored). The system does not auto-fill them — you copy/paste manually when logging in. The dashboard never shows a stored password unless you click Reveal.

          AI provider keys — environment

          API keys for the AI extractor are read from environment Secrets (e.g. ANTHROPIC_API_KEY, GEMINI_API_KEY). Set or change them in your host's Secrets and republish — Replit encrypts and persists Secrets across redeploys. There is no in-app key store and no master key, so a key can never show as "locked". Values are never displayed. SESSION_SECRET is unrelated.
